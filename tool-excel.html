Excel editor

Shortcuts
  • Ctrl/Cmd + S: Save sheet
  • Ctrl/Cmd + B: Toggle bold on selected cell
  • Ctrl/Cmd + I: Toggle italic on selected cell
  • Ctrl/Cmd + U: Toggle underline on selected cell
  • Ctrl/Cmd + D: Fill down from the cell above
  • Ctrl/Cmd + R: Fill right from the cell on the left
  • Ctrl/Cmd + Home: Jump to A1
  • Ctrl/Cmd + End: Jump to last used cell
  • Ctrl/Cmd + Arrow Keys: Jump to edge of data region
  • Ctrl/Cmd + ;: Insert current date
  • Ctrl/Cmd + Shift + ;: Insert current time
  • Delete: Clear selected cell
  • Enter/Shift + Enter: Move down/up
  • Tab/Shift + Tab: Move across cells (wrap at row edges)
  • Home/End: Jump to start/end of current row
  • Arrow keys: Move cell selection
  • Alt + H/N/M/A/R: Switch ribbon tabs (Home/Insert/Formulas/Data/Review)

Cells auto-save to server storage (prototype mock). You can export CSV at any time.
